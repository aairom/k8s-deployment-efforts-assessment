2. Solution Overviews

IBM Kubernetes Service (IKS)

Vanilla CNCF-certified Kubernetes — IBM Cloud

  • Dedicated control plane, fully managed by IBM
  • Worker nodes: Ubuntu 22.04 LTS / RHEL 8
  • containerd runtime, Calico CNI plugin
  • Native IBM Cloud IAM, Key Protect, ICR integration
  • ISO 27001, SOC 2, PCI DSS, HIPAA
  • Lowest cost entry point in IBM Cloud
ROKS — Red Hat OpenShift on IBM Cloud

Managed OpenShift Container Platform 4.x — IBM Cloud

  • Dedicated OCP control plane, fully managed by IBM
  • Immutable RHCOS worker nodes, SELinux enforcing
  • CRI-O runtime, SCC by default
  • OperatorHub, Tekton, S2I, Web Console integrated
  • Required for IBM Cloud Paks
  • FIPS 140-2, FedRAMP, DoD CC SRG
Self-Managed Kubernetes

On-premises / unmanaged IaaS — Own infrastructure

  • Full control: version, configuration, components
  • kubeadm, k3s, RKE2, Talos, Rancher…
  • Maximum operational burden (etcd, PKI, CNI, CSI)
  • Minimal vendor lock-in
  • Designed for air-gapped & data sovereignty
  • Advanced SRE expertise mandatory
Amazon EKS

Managed CNCF-certified Kubernetes — Amazon Web Services

  • Multi-AZ control plane managed by AWS
  • EC2 Managed Node Groups + Fargate (serverless)
  • AWS VPC CNI (native VPC IPs for pods)
  • Native: AWS IAM, EBS/EFS/FSx, ECR, ALB
  • EKS Anywhere for on-premises deployments
  • SOC, PCI, ISO, HIPAA, FedRAMP

14. Recommendations by Profile

Profile 1 — Native IBM Cloud Enterprise

→ IKS or ROKS

  • IKS: pure containerized workloads, minimum cost, expert K8s teams
  • ROKS: IBM Cloud Paks, regulated industry (FIPS, FedRAMP), hybrid OpenShift
  • ROKS: integrated developer experience required
  • Red Hat BYOL: ROKS at IKS cost
Profile 2 — Hybrid / Multi-Cloud Organization

→ ROKS (via IBM Cloud Satellite)

  • Operational consistency: IBM Cloud ↔ on-premises ↔ other clouds
  • Same oc CLI, SCCs, OperatorHub across all environments
  • IBM ACM for centralized multi-cluster governance
  • IBM Cloud Paks on Satellite
Profile 3 — AWS-Native Organization

→ Amazon EKS

  • Already invested in AWS ecosystem (IAM, VPC, RDS, S3, Lambda)
  • Native integration with all AWS services + AWS Marketplace
  • Fargate for serverless workloads without node management
  • Karpenter for real-time EC2 cost optimization
Profile 4 — Data Sovereignty / Mandatory On-Premises

→ Self-Managed Kubernetes

  • Regulatory requirements prohibiting public cloud
  • Existing owned infrastructure to leverage
  • Commercial distribution recommended (Rancher, Tanzu)
  • ⚠️ Real TCO regularly exceeds estimates — SRE expertise mandatory

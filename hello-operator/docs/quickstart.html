3. Clone and Build

3.1 Clone the Repository

git clone https://github.com/example/hello-operator.git
cd hello-operator

3.2 Download Dependencies

go mod tidy

3.3 Compile the Manager Binary

make build

The binary is written to bin/manager. Verify:

./bin/manager --help
Expected output: Usage flags for --leader-elect, --metrics-bind-address, --health-probe-bind-address.

4. Generate CRD Manifests

Skip this step if you haven't modified the API types in api/v1alpha1/helloworld_types.go. The pre-generated manifests in config/crd/bases/ are ready to use. 
# Install controller-gen locally
make controller-gen

# Regenerate CRD YAML and RBAC from Go annotations
make manifests

# Regenerate DeepCopy methods
make generate

5. Build and Push the Operator Image

5.1 Set the Image Variable

export IMG=<your-registry>/hello-operator:v0.1.0

5.2 Build the Image

make docker-build IMG=$IMG

Multi-stage build: golang:1.21-alpine (compiler) → distroless/static-debian11:nonroot (runtime).

5.3 Registry Login

# Docker Hub
docker login

# IBM Cloud Container Registry
ibmcloud cr login

# Amazon ECR
aws ecr get-login-password --region <region> | \
  docker login --username AWS --password-stdin <account-id>.dkr.ecr.<region>.amazonaws.com

# Google Artifact Registry
gcloud auth configure-docker <region>-docker.pkg.dev

# Azure Container Registry
az acr login --name <registry-name>

5.4 Push the Image

make docker-push IMG=$IMG

5.5 Multi-Architecture Build (optional)

make docker-buildx IMG=$IMG

6. Deploy the Operator

6.1 Install the CRD

make install
# Verify
kubectl get crd helloworlds.apps.example.com
NAME                            CREATED AT
helloworlds.apps.example.com    2026-09-03T13:40:00Z

6.2 Deploy the Operator Pod

make deploy IMG=$IMG

6.3 Verify

kubectl -n hello-operator-system get pods
NAME                                                    READY   STATUS    RESTARTS   AGE
hello-operator-controller-manager-6d9f8c4b7d-xk4pl     1/1     Running   0          45s
# Stream operator logs
kubectl -n hello-operator-system logs \
  -l control-plane=controller-manager --follow
OpenShift / ROKS: Grant anyuid SCC to allow the http-echo image to run:

oc adm policy add-scc-to-serviceaccount anyuid -n default -z default

7. Apply the Sample Custom Resource

kubectl apply -f config/samples/apps_v1alpha1_helloworld.yaml

Or inline:

kubectl apply -f - <<EOF
apiVersion: apps.example.com/v1alpha1
kind: HelloWorld
metadata:
  name: my-hello
  namespace: default
spec:
  replicas: 1
  message: "Hello from kubectl!"
  serviceType: ClusterIP
EOF

8. Verify the Deployment

List HelloWorld Resources

kubectl get helloworld -A    # or: kubectl get hw -A
NAMESPACE   NAME                 REPLICAS   READY   MESSAGE                          AGE
default     helloworld-sample    2          2       Hello from the hello-operator!   30s

Check Pods and Service

kubectl get pods -l app.kubernetes.io/managed-by=hello-operator
kubectl get svc  -l app.kubernetes.io/managed-by=hello-operator

Inspect Status Conditions

kubectl describe helloworld helloworld-sample
Conditions:
  Type         Status  Reason               Message
  Available    True    DeploymentAvailable  2/2 replicas available
  Progressing  False   DeploymentAvailable  Deployment is fully available
  Degraded     False   DeploymentAvailable  Deployment is healthy

9. Access the Hello World Application

Option A: Port-Forward (All Platforms)

kubectl port-forward svc/helloworld-sample-service 8080:80
curl http://localhost:8080
# Output: Hello from the hello-operator!

Option B: LoadBalancer (Cloud)

kubectl patch helloworld helloworld-sample \
  --type=merge \
  -p '{"spec":{"serviceType":"LoadBalancer"}}'

kubectl get svc helloworld-sample-service --watch

EXTERNAL_IP=$(kubectl get svc helloworld-sample-service \
  -o jsonpath='{.status.loadBalancer.ingress[0].ip}')
curl http://${EXTERNAL_IP}

Option C: NodePort (On-Premises)

kubectl patch helloworld helloworld-sample \
  --type=merge \
  -p '{"spec":{"serviceType":"NodePort"}}'

NODE_PORT=$(kubectl get svc helloworld-sample-service \
  -o jsonpath='{.spec.ports[0].nodePort}')
NODE_IP=$(kubectl get nodes \
  -o jsonpath='{.items[0].status.addresses[?(@.type=="InternalIP")].address}')
curl http://${NODE_IP}:${NODE_PORT}

Option D: OpenShift Route (ROKS / OCP)

oc expose svc helloworld-sample-service
oc get route helloworld-sample-service

10. Update the Custom Resource

Scale Replicas

kubectl patch helloworld helloworld-sample \
  --type=merge \
  -p '{"spec":{"replicas":3}}'

kubectl get pods -l app.kubernetes.io/managed-by=hello-operator --watch

Change the Message

kubectl patch helloworld helloworld-sample \
  --type=merge \
  -p '{"spec":{"message":"Updated message!"}}'

kubectl port-forward svc/helloworld-sample-service 8080:80 &
curl http://localhost:8080
# Output: Updated message!

Watch Reconciliation Logs

kubectl -n hello-operator-system logs \
  -l control-plane=controller-manager --follow
{"level":"info","logger":"controller.helloworld","msg":"Updating Deployment","name":"helloworld-sample-deployment"}
{"level":"info","logger":"controller.helloworld","msg":"Updating Service","name":"helloworld-sample-service"}

11. Cleanup

Delete the Sample HelloWorld

kubectl delete -f config/samples/apps_v1alpha1_helloworld.yaml
# Owned Deployment and Service are garbage-collected automatically.

Remove the Operator

make undeploy

Remove the CRD

make uninstall
# or manually:
kubectl delete crd helloworlds.apps.example.com
Warning: Deleting the CRD removes all HelloWorld instances cluster-wide. Delete all instances first if you want to preserve anything.

12. Troubleshooting

General Debugging Commands

# Operator pod status
kubectl -n hello-operator-system get pods

# Operator logs
kubectl -n hello-operator-system logs \
  -l control-plane=controller-manager --tail=100

# Describe a HelloWorld resource
kubectl describe helloworld helloworld-sample

# Recent events
kubectl get events --sort-by='.lastTimestamp'

Error: no matches for kind "HelloWorld"

Cause: CRD not installed.

make install

Error: ImagePullBackOff on Operator Pod

Cause: Registry credentials missing or wrong image name.

# Create pull secret
kubectl -n hello-operator-system create secret docker-registry regcred \
  --docker-server=<registry> \
  --docker-username=<user> \
  --docker-password=<password>

kubectl -n hello-operator-system patch serviceaccount \
  hello-operator-controller-manager \
  -p '{"imagePullSecrets": [{"name": "regcred"}]}'

Error: forbidden: cannot create resource "deployments"

Cause: RBAC not applied correctly.

kubectl apply -f config/rbac/role.yaml
kubectl apply -f config/rbac/role_binding.yaml

# Verify permissions
kubectl auth can-i create deployments \
  --as=system:serviceaccount:hello-operator-system:hello-operator-controller-manager

OpenShift / ROKS: CreateContainerConfigError

Cause: hashicorp/http-echo runs as root; blocked by the restricted SCC.

oc adm policy add-scc-to-serviceaccount anyuid -n default -z default

EKS: exec plugin: invalid apiVersion

Cause: AWS CLI / kubeconfig token plugin version mismatch.

pip install --upgrade awscli
aws eks update-kubeconfig --region <region> --name <cluster-name>

GKE: Forbidden when Applying CRD

Cause: kubectl context user lacks cluster-admin.

kubectl create clusterrolebinding cluster-admin-binding \
  --clusterrole=cluster-admin \
  --user=$(gcloud config get-value core/account)

IKS: RBAC: access denied Creating CRD

Cause: IAM user not mapped to cluster-admin.

ibmcloud ks cluster config --cluster <cluster-name>
kubectl create clusterrolebinding my-admin \
  --clusterrole=cluster-admin \
  --user=<your-ibmcloud-iam-id>

AKS: no matches for kind "Kustomization"

Cause: Old kubectl / kustomize version.

az aks install-cli          # update kubectl
make kustomize              # install bundled kustomize
./bin/kustomize build config/default | kubectl apply -f -
